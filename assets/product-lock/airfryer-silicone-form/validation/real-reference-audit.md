## Видео IMG_5925.MOV — покадровый разбор

Извлечено 16 равномерных кадров (frame 0, 67, 133, …, 998). Содержание:
владелец достаёт форму, показывает дно и ручки, затем ставит форму в реальный
аэрогриль **DE'MIAND** (эмблема и сенсорная панель с русскими подписями:
СВЕТ, ТЕМП/ВРЕМЯ, WIFI, СТЕЙК, РЫБА, ВЫПЕЧКА, ПИЦЦА, СОСИСКИ, КАРТОФЕЛЬ ФРИ,
БЕКОН, ПРОГРЕВ, ВКЛ/ВЫКЛ, МЕНЮ), затем вынимает — виден чистый пустой родной
пластиковый лоток аэрогриля (спиральный вентиляционный узор, круглая крышка
по центру).

**Важные кадры:**
- `mov-frame-0865` — фронтальный вид аэрогриля целиком, панель управления и
  логотип читаются полностью. Лучший кандидат на канонический аэрогриль.
- `mov-frame-0998` (последний) — пустой чистый родной лоток БЕЗ формы,
  резкий, хорошо освещён. Идеальная замена для scene-06 (сейчас там
  AI-референс `place.png`).
- `mov-frame-0931` — форма внутри родного лотка аэрогриля (видна ПРАВАЯ
  ручка целиком, рука держит верх).
- Множество кадров с мужской рукой (0333, 0466, 0665, 0732, 0798, 0865,
  0931, 0998) — держит форму за одну ручку сверху, большой палец видно на
  ручке. Полезно как референс механики захвата, но **не для гендера рук**
  (Visual Bible требует женские руки без украшений; здесь рука мужская, на
  запястье фитнес-браслет).

**Проблема цвета**: кадры, извлечённые из MOV через PyAV, выглядят бледными
(форма читается почти серо-голубой, а не тёмно-графитовой) — похоже на
артефакт цветового диапазона декодера (limited vs full range), а не
реальный цвет товара. Достоверный цвет — по JPG-фото (там форма
корректно тёмно-серая матовая). **Рекомендация: для цвета доверять
фотографиям, видео использовать только для геометрии/движения/аэрогриля.**

## Сравнение с текущим Visual Bible / product-lock

### Геометрия ручек — КРИТИЧЕСКОЕ РАСХОЖДЕНИЕ

Прямое сопоставление `forma_6angles.png` (текущий "канонический" источник
всего product-lock пакета) и реальных фото показывает: **это разные
конструкции ручек**.

| | `forma_6angles.png` (текущий канон) | Реальный товар (photo_2/3/7, видео) |
|---|---|---|
| Силуэт | высокая ручка-петля, поднимается заметно НАД кромкой бортика | плоский угловой выступ-язычок, почти вровень с кромкой |
| Вырез | узкий вытянутый овал, вертикально ориентированный | короткая прямоугольная/скруглённая прорезь, горизонтальная |
| Положение | по центру верхнего края стенки, в виде дуги-ручки для переноски | в верхнем углу стенки, встроен в изгиб бортика |
| Толщина рамки | равномерная тонкая петля | толще, часть общего профиля стенки |

Это означает: **весь product_lock.json / handles_reference_crop.png / вся
предыдущая борьба с "handle_geometry_mismatch" опирались на референс,
который сам не совпадает с реальным товаром.** AI не просто "перерисовывал
geometрию мимо канона" — сам канон был неточным. Реальные фото — первый
достоверный источник геометрии ручек за всю кампанию.

**Форма/пропорции/материал/дно**, однако, совпадают хорошо: тёмно-серый
матовый силикон, квадрат со скруглёнными углами, рифлёное дно с
параллельными выступающими рёбрами, круглая петля-держатель по центру дна
(видна и на `forma_6angles.png`, и на photo_5/6) — этот элемент подтверждён
реальными фото и остаётся валидным.

### Аэрогриль — расхождение

Visual Bible описывает "современный чёрный аэрогриль с прозрачным
смотровым окном спереди" (референс `video2-formaad/place.png`, AI-кадр).
Реальный аэрогриль — **DE'MIAND**, выдвижной ящик с сенсорной панелью
управления сверху (без круглого смотрового окна в прежнем понимании; в
открытом виде видно тонкое смотровое стекло на передней грани ящика).
Дизайн другой. Требуется решение владельца: заменить `place.png` на реальный
`mov-frame-0865`/`mov-frame-0998` как канон, либо намеренно оставить
"обобщённый" AI-дизайн для бренд-нейтральности. **Не выбираю сам, это
open decision.**

### Кухня — расхождение (контекстное, не обязательно проблема)

Visual Bible: белый кабанчик-фартук, светлая каменная столешница, деревянная
доска, растение. Реальные фото сняты на чёрной индукционной плите DEXP на
фоне бежевого/коричневатого мраморного фартука — другая кухня. Это, скорее
всего, просто "тестовая" кухня для фотосета геометрии, а не обязательный
новый канон интерьера. **Open decision**, не меняю Visual Bible сам.

### Руки — пока не закрыто

Реальные руки в видео/фото — мужские, с фитнес-браслетом, что запрещено
правилами кампании (женские руки без украшений). Это **не** финальный
референс рук; фотосет женских рук всё ещё требуется
(`REAL_PRODUCT_REFERENCE_SHOOT.md`, кадры 12–13).

## Что теперь можно закрыть как решённое

1. **Геометрия ручек товара** — впервые есть достоверный источник (было
   requires_real_photo → теперь ЗАКРЫТО данными, но требует пересборки
   product asset pack, не выполнено в этом аудите).
2. **Аэрогриль (личность/бренд)** — есть чёткий фронтальный кадр и кадр
   чистого пустого лотка (было requires_real_photo → материал ЕСТЬ, решение
   об использовании — за владельцем).
3. **Форма в реальном лотке аэрогриля** — есть кадр (mov-frame-0931),
   частично закрывает пробел "форма в корзине" для сцен 03/04/05.
4. **Дно/круглая петля-держатель** — подтверждено реальными фото, элемент
   Visual Bible валиден, менять не нужно.

## Чего всё ещё не хватает

1. **Форма С ЕДОЙ** — ни одного кадра; по-прежнему requires_real_photo.
2. **Женские руки без украшений**, держащие форму за ручки — все реальные
   руки в этом сете мужские; требуется отдельный фотосет.
3. **Фронтальный ракурс формы на уровне глаз** (medium shot, как в
   исходном scene-05) — есть только сверху/3-4/профиль/дно, нет вида "почти
   в упор спереди на уровне стола", как использовалось в сценах.
4. **Чистая кухня по правилам Visual Bible** (если решено её сохранить) —
   реальные фото сняты в другом интерьере.
5. Решение владельца: заменять ли `forma_6angles.png` /
   `handles_reference_crop.png` / `place.png` целиком на реальные ассеты,
   или оставить старые как "стилизованный бренд-канон" и использовать
   новые фото только для физической точности геометрии. Это архитектурное
   решение, не принимаю его сам.
